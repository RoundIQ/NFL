Where the file comes from
nflverse publishes weekly player stats as a public CSV, no key or account. Every row carries the player's position and his opponent, so one file gives both player usage and what each defense allowed by position. If auto-fetch is blocked, download it yourself and load it here — same data, and it only updates once a week.

Where: github.com/nflverse/nflverse-data/releases → find the stats_player release → download stats_player_week_YYYY.csv

Take the plain .csv, not .csv.gz, .rds or .parquet — the browser cannot read those. The file is large (roughly 20,000 rows and 150 columns), so give it a few seconds to parse.
